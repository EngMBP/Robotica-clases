Clase 03 · Unidad 1 · Herramientas de diseño y análisis de proceso

Modelado CAD de piezas · Teoría y primeros pasos

Encuentro virtual sincrónico Pendiente

Objetivos de la clase

  • Entender qué es el diseño paramétrico y por qué es la base del CAD moderno.
  • Conocer la jerarquía de un proyecto CAD: piezas, ensambles y planos.
  • Dominar el flujo de diseño de una pieza: boceto → volumen → acabados.
  • Aplicar restricciones geométricas y cotas para resolver completamente un boceto.
  • Practicar las buenas prácticas de estructura del árbol de operaciones.

¿Qué es el diseño paramétrico?

El diseño paramétrico es una forma de crear geometría en la que cada elemento no se dibuja de forma libre y definitiva, sino que se define a partir de relaciones y valores (parámetros) que quedan vivos dentro del modelo. Esto significa que una pieza no es un dibujo fijo, sino un conjunto de instrucciones geométricas y numéricas: si cambio un parámetro (una medida, un ángulo, una relación), todo el modelo se recalcula automáticamente respetando esas reglas.

La palabra clave es histórico y relacional: cada operación que hacés queda guardada en un árbol de construcción, y cada paso nuevo depende de los anteriores. Esto es lo que le da al CAD paramétrico su poder principal: la capacidad de modificar un diseño completo cambiando pocos valores, sin tener que rehacer todo desde cero.

¿Qué es una herramienta CAD?

CAD significa Diseño Asistido por Computadora (Computer Aided Design). Es un software que permite crear representaciones digitales tridimensionales de piezas y ensambles, con toda la información geométrica, dimensional y de material necesaria para luego fabricarlas, documentarlas o simularlas.

Ejemplos: SolidWorks, Autodesk Inventor, CATIA, Fusion 360, OnShape, Siemens NX. Todas comparten los mismos conceptos fundamentales aunque cambien nombres de comandos y ubicación de menús — y ese es justamente el objetivo de este curso: enseñar esos conceptos comunes.

De qué se compone un proyecto CAD

Un proyecto CAD se estructura en tres niveles jerárquicos:

Pieza (Part)
El elemento más básico, un único cuerpo sólido diseñado como una unidad. Contiene croquis, operaciones de volumen y acabados, todo grabado en un árbol de historial paramétrico.
Ensamble (Assembly)
Una combinación de piezas (y/o sub-ensambles) vinculadas entre sí mediante relaciones posicionales. Permite verificar que todas las piezas encajen sin interferencias.
Plano (Drawing)
La documentación técnica bidimensional que se genera a partir de la pieza o el ensamble, para fabricación o comunicación técnica. Es un vínculo vivo con el modelo 3D.

Origen de las piezas: diseñadas vs. comerciales

Dentro de un ensamble, las piezas que lo componen pueden tener dos orígenes distintos:

Piezas diseñadas a medida
Geometría creada específicamente por nosotros para cumplir una función particular del proyecto. Viven en el árbol paramétrico y pueden modificarse sin límite.
Componentes comerciales (off-the-shelf)
Elementos estandarizados que ya existen en el mercado y se compran, no se diseñan: tornillos, tuercas, arandelas, rodamientos, resortes, válvulas, actuadores, etc. Muchas veces se consiguen como archivos CAD descargables directamente del fabricante. Nunca se modifican — representan una pieza que se compra tal cual.

Ambos tipos de piezas conviven dentro de un mismo ensamble, y esa combinación es la que da lugar a subensambles, que a su vez pueden integrarse en ensambles de mayor nivel hasta llegar al ensamble final del producto completo.

Flujo de diseño de una pieza

El proceso de creación de una pieza sigue siempre esta lógica, sin importar el software:

  1. Boceto (Sketch) 2D: se dibuja la geometría base sobre un plano de referencia usando líneas, círculos, arcos, rectángulos, etc.
  2. Restricciones y cotas: se define cómo se relacionan esos elementos entre sí (paralelismo, concentricidad, simetría) y qué medidas fijan su tamaño real.
  3. Operación de volumen: el boceto 2D resuelto se transforma en un sólido 3D mediante una operación como extruir, revolucionar, barrer o solevar.
  4. Operaciones de acabado/modificación: sobre el sólido ya generado se aplican redondeos, chaflanes, vaciados (cascarón), nervaduras o patrones repetitivos.
  5. Árbol de historial paramétrico: todo el proceso queda guardado como una secuencia de pasos dependientes entre sí. Si se modifica un valor temprano en el árbol, todo lo posterior se recalcula automáticamente.

Restricciones geométricas

Un boceto debe estar completamente restringido antes de convertirlo en volumen. Las restricciones geométricas definen cómo se relacionan los elementos:

  • Coincidente
  • Paralelo
  • Perpendicular
  • Tangente
  • Concéntrico
  • Colineal
  • Simétrico
  • Punto medio
  • Horizontal / Vertical

Restricciones dimensionales (cotas)

Fijan valores numéricos concretos:

  • Longitudes
  • Ángulos
  • Radios
  • Distancias
Regla esencial

El boceto se considera "resuelto" cuando queda completamente restringido: no debe quedar geometría con libertad de movimiento no intencional (subrestringido) ni relaciones contradictorias (sobrerrestringido). La mayoría de herramientas CAD lo indican con un cambio de color en la geometría (generalmente blanca/azul cuando está resuelto).

Herramientas fundamentales de boceto

Geometría de dibujo

  • Línea
  • Rectángulo
  • Círculo
  • Arco
  • Elipse
  • Polígono
  • Spline (curva libre)

Herramientas de modificación 2D

  • Desplazamiento / Offset
  • Espejo (mirror)
  • Patrón lineal o circular
  • Recortar (trim)
  • Extender (extend)
  • Chaflán y redondeo 2D

Operaciones básicas para generar volumen

Extruir (Extrude)
Empuja la silueta del boceto en línea recta una distancia determinada. Es la más común.
Revolucionar (Revolve)
Gira la silueta alrededor de un eje, generando formas de simetría circular (ejes, tornillos, poleas).
Barrer (Sweep)
Desliza la silueta a lo largo de una trayectoria curva definida (tubos, molduras, perfiles ondulados).
Solevado (Loft)
Genera una transición suave de geometría entre dos o más secciones ubicadas en distintos planos (carcasas, fuselajes).

Operaciones de modificación del sólido

Redondeo (Fillet)
Suaviza aristas. Reduce concentraciones de esfuerzo y mejora la apariencia.
Chaflán (Chamfer)
Corta las aristas en ángulo, típicamente para monaje o para evitar que se enganche geometría.
Cascarón / Vaciado (Shell)
Convierte un sólido en una pared hueca con espesor uniforme.
Nervaduras o costillas de refuerzo (Rib)
Agrega nervios internos que aumentan rigidez sin agregar peso.
Orden de operaciones

El orden importa. Redondear antes de cortar puede hacer que el corte falle al cambiar una medida. Regla práctica: primero el volumen principal, después los cortes funcionales —agujeros, alojamientos— y al final los detalles estéticos y de seguridad.

Patrones y simetrías en 3D

  • Patrón lineal: repite una operación a lo largo de una línea.
  • Patrón circular: repite una operación alrededor de un eje.
  • Espejo de pieza completa (mirror body): crea una copia especular de toda la geometría.

Planos y ejes de referencia auxiliares

Geometría de referencia (planos, ejes, puntos) que se crea cuando los planos por defecto no alcanzan para apoyar un nuevo boceto o una nueva operación. Es fundamental para piezas complejas con geometría en ángulos o ubicaciones no estándar.

Ejercicio de CAD

Modelar una pieza simple —un soporte en L o una brida— usando únicamente extrusión, corte y redondeos. Requisitos:

  • Croquis totalmente restringido.
  • Al menos un agujero pasante y uno ciego.
  • Redondeos aplicados al final del árbol.
  • Cambiar una cota principal al terminar y verificar que la pieza se reconstruye sin errores.
